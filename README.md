# ESP Dimmer

Многоканальный регулятор яркости на ESP8266/ESP32.

## Цель проекта

Финальная конфигурация:

- 3 независимых канала;
- отдельная кнопка каждого канала;
- 1 master-кнопка для общего включения/выключения;
- PWM 1 кГц;
- рабочая яркость каждого канала 10–100%;
- после перезапуска все каналы выключены.

## Управление каналом

| Действие | Результат |
|---|---|
| Короткое нажатие (`< 450 мс`) | Включение/выключение канала; яркость сохраняется в RAM |
| Удержание | Плавное изменение яркости |
| Следующее удержание | Изменение яркости в обратную сторону |
| Удержание из OFF | Включение с 10% и плавное увеличение |

## Master-кнопка

На текущем NodeMCU-стенде master использует физическую пятую кнопку на `D0 / GPIO16`.

Логика master toggle:

- если включён хотя бы один канал — выключить все 3;
- если все 3 канала выключены — включить все 3 на их сохранённой яркости.

Схема подключения: [docs/wiring.md](docs/wiring.md).

## Текущий стенд NodeMCU ESP8266

- CH1: LED `D1`, BTN `D3`;
- CH2: LED `D2`, BTN `D4`;
- CH3: LED `D5`, BTN `D7`;
- MASTER: BTN `D0` → `3V3`, active HIGH через `INPUT_PULLDOWN_16`.

Ранее использовавшиеся `D6/D9` и `D8` в текущей прошивке не задействованы.

## Сборка

По умолчанию используется окружение `nodemcuv2`.

```bash
pio run
```

Прошивка:

```bash
pio run -t upload
```

Serial Monitor:

```bash
pio device monitor
```

Для будущего ESP32-C3 предусмотрено отдельное окружение `esp32c3`.
