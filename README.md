# ESP Dimmer

Многоканальный регулятор яркости на ESP8266/ESP32 с управлением одной кнопкой на канал.

## Цель проекта

Для каждого канала:

- короткое нажатие — включение/выключение;
- удержание — плавное увеличение яркости;
- следующее удержание — плавное уменьшение яркости;
- рабочий диапазон яркости — 10–100%;
- PWM — 1 кГц;
- после перезапуска все каналы остаются выключенными.

Планируемая финальная конфигурация — до 5 независимых каналов и опциональная master-кнопка.

## Текущий этап

Первый стенд собирается на NodeMCU ESP8266:

- 1 внешний светодиод;
- 1 тактовая кнопка;
- PlatformIO + Arduino framework.

Схема подключения первого стенда: [docs/wiring.md](docs/wiring.md).

После отладки логики проект будет перенесён на ESP32-C3 SuperMini для многоканальной версии.

## Сборка

По умолчанию используется окружение `nodemcuv2`.

```bash
pio run
```

Прошивка:

```bash
pio run -t upload
```

Serial Monitor:

```bash
pio device monitor
```

Для будущего ESP32-C3 предусмотрено отдельное окружение `esp32c3`.
