# Схема тестового стенда

Текущая конфигурация на **NodeMCU ESP8266**: **3 независимых канала + 1 master-кнопка**.

## Что изменилось

Ранее стенд использовал 5 каналов. Теперь в финальной логике нужны только 3 канала, поэтому физическую пятую кнопку переиспользуем как master.

Важно: проводку самой пятой кнопки менять не нужно — она уже подключена как `D0 -> кнопка -> 3V3` и работает через `INPUT_PULLDOWN_16`.

Ранее использовавшиеся:

- LED4 на `D6`;
- BTN4 на `D9/RX`;
- LED5 на `D8`

в текущей прошивке не используются.

## Распиновка

| Назначение | LED / PWM | Кнопка | Логика кнопки |
|---|---|---|---|
| Канал 1 | `D1 / GPIO5` | `D3 / GPIO0` → GND | active LOW, `INPUT_PULLUP` |
| Канал 2 | `D2 / GPIO4` | `D4 / GPIO2` → GND | active LOW, `INPUT_PULLUP` |
| Канал 3 | `D5 / GPIO14` | `D7 / GPIO13` → GND | active LOW, `INPUT_PULLUP` |
| MASTER | — | `D0 / GPIO16` → `3V3` | active HIGH, `INPUT_PULLDOWN_16` |

## Схема

```text
                         NodeMCU ESP8266
                      ┌─────────────────────┐
                   D1 ●── 10k ──►|── GND      LED ch1
                   D2 ●── 10k ──►|── GND      LED ch2
                   D5 ●── 10k ──►|── GND      LED ch3
                      │
                   D3 ●── [BTN1] ── GND
                   D4 ●── [BTN2] ── GND
                   D7 ●── [BTN3] ── GND
                      │
                   D0 ●── [MASTER] ── 3V3
                      │    active HIGH
                      │    INPUT_PULLDOWN_16
                  GND ●──────────────────── общий GND
                      └─────────────────────┘

Питание: micro-USB
```

## Master-кнопка

Master имеет обычный debounce, но не имеет функции регулировки яркости при удержании. Срабатывание происходит один раз на нажатие.

Алгоритм:

```text
если хотя бы один из CH1..CH3 включён
    MASTER -> выключить все три
иначе
    MASTER -> включить все три
```

При master OFF значения яркости каналов не сбрасываются. Следующее master ON включает каждый канал на его сохранённой в RAM яркости.

После reboot, как и раньше, все каналы стартуют в состоянии OFF.

## Подключение обычных кнопок

Кнопки каналов 1–3:

```text
PIN -------- [ BUTTON ] -------- GND
```

Отпущена = HIGH, нажата = LOW.

Master:

```text
D0 -------- [ MASTER ] -------- 3V3
 |
 +--- INPUT_PULLDOWN_16 ---> GND
```

Отпущена = LOW, нажата = HIGH. Внешний pull-up/pull-down резистор не нужен.

## Важные замечания

1. `D3 / GPIO0` и `D4 / GPIO2` — boot-strap GPIO. Не держите BTN1/BTN2 нажатыми при включении питания или Reset.
2. `D0 / GPIO16` выбран под master именно из-за `INPUT_PULLDOWN_16`; GPIO16 технически умеет software PWM, но в этой схеме выгоднее использовать его как вход кнопки без внешнего резистора.
3. `D9/RX`, `D6` и `D8` теперь свободны и текущей прошивкой не используются.
4. Резисторы 10 кОм на LED допустимы для теста, но светодиоды будут очень тусклыми. Для нормальной индикации лучше примерно `330–470 Ω`.

## Что проверяем

- CH1, CH2, CH3 независимо включаются/выключаются;
- удержание каждой кнопки меняет яркость только своего канала;
- master при любом включённом канале выключает все три;
- master при полностью выключенных каналах включает все три;
- после master OFF/ON индивидуальная яркость каждого канала сохраняется;
- после перезапуска все три канала выключены;
- PWM каждого канала — 1 кГц, диапазон яркости 10–100%.
