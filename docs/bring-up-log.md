# Журнал bring-up: issue #3

Рабочий протокол эталонного канала, затем четырёх каналов. Принципиальная схема: [assets/schematics/load-control-channel.svg](assets/schematics/load-control-channel.svg). Pinout корпусов: [assets/schematics/component-pinouts.svg](assets/schematics/component-pinouts.svg). План: [load-control-plan.md](load-control-plan.md). Issue: https://github.com/Web-Usov/esp-dimmer/issues/3

Firmware, PWM frequency и inversion **не менять**. Опциональный `50 kΩ BASE → DIM−` **не ставить**. Каждый gate — запись сюда и копией в issue. Следующий шаг не начинать без измерений текущего.

Пины эталона: PWM **GPIO0 (CH1)**, кнопка CH1 GPIO5, master GPIO20. Все кнопки → GND.

## Safety

- 230 VAC не собирать на breadboard. Первичная сторона LPV — готовый узел.
- Перестановки `PC817 / BC548 / DIM / ESP` — только после полного отключения питания.
- Не соединять `DIM−` с `Vout−`, `ESP GND` с `DIM−` / `Vout−`.
- Не подключать ESP одновременно к USB и внешним 5 V, пока power-path SuperMini не проверен.
- Выход LDH — не «12 V линия» (до десятков вольт).

## Фаза 0. Pinout и сборка эталона

Ожидаемый pinout по datasheet проекта (проверять на конкретной детали):

| Корпус | Ориентация | Выводы |
|---|---|---|
| PC817 DIP-4 | вид сверху, выемка сверху, pin 1 слева сверху | 1 Anode, 2 Cathode, 3 Emitter, 4 Collector |
| BC548 TO-92 onsemi | плоская грань к себе, выводы вниз | 1 Collector, 2 Base, 3 Emitter |

Прозвонка BC548 (NPN, обесточено, DIP-метр диодный режим):

- Красный на B (pin 2), чёрный на E (pin 3) → ~0.6 V.
- Красный на B (pin 2), чёрный на C (pin 1) → ~0.6 V.
- Обратно и C–E → обрыв.
- Если картина не сходится — **не паять по рисунку**, записать маркировку корпуса в issue.

Прозвонка PC817:

- Pin 1 → pin 2 как LED, одна сторона ~1.1–1.4 V.
- Pin 4–3 в темноте — высокий сопротивление.

Сборка (50 kΩ нет):

```text
GPIO0 ──┬── R1 500 Ω ── PC817 pin 1 Anode
        └── R2 10 kΩ ── ESP GND
PC817 pin 2 Cathode ── ESP GND

PC817 pin 4 Collector ── BC548 pin 2 Base
BC548 pin 2 Base ── R3 10 kΩ ── DIM+
BC548 pin 1 Collector ── DIM+
BC548 pin 3 Emitter ── DIM−
PC817 pin 3 Emitter ── DIM−
```

| Проверка | Факт | Pass |
|---|---|---|
| Маркировка PC817 | не записана; 1→2 = 1168 мВ, 2→1 = OL, 4→3 = OL | да (pinout) |
| Маркировка BC548 | не записана | |
| DMM B-E / B-C ~0.6 V | B-E 623 мВ, B-C 623 мВ (C-B-E) | да |
| 50 kΩ не установлен | модуль к DIM ещё не собран | |
| ESP GND не соединён с DIM− | модуль к DIM ещё не собран | |

**Gate 0 pinout:** PC817 и BC548 сверены. Сборка к DIM — после фазы 2.

## Фаза 3. Только BC548

```text
C (pin 1) -> DIM+
E (pin 3) -> DIM−
10 kΩ: DIM+ -> B (pin 2)
```

PC817 и ESP не подключены.

| Состояние | LED | DIM+ − DIM− | Нагрев BC548 | Pass |
|---|---|---|---|---|
| Покой (BASE к DIM+) | тлеет, не полный OFF | 0.60 V (после swap C/E: 0.90 V, хуже; вернули) | не сообщалось | нет: не 0 V |
| BASE временно к DIM− | | | | |

Отклонение: 10 kΩ с DIM+ на базу даёт зажим ≈ VBE. Ниже ~0.6 V эта схема не опускает DIM, LDH поэтому тлеет. Проводка C / 10k / B / E на трёх колонках — как в плане. PC817 пока не добавлять.

**Gate 3:** не закрыт, пока нет полного OFF в покое. Следующий тычок — BASE к DIM− (ожидание full ON).
