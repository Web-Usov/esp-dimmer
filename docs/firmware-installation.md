# Установка готовой прошивки ESP Dimmer

Для обычной установки ESP Dimmer на **ESP32-C3** не нужны исходники, PlatformIO, Python или Arduino IDE.

## Вариант 1 — Web Installer (рекомендуется)

Откройте:

**https://web-usov.github.io/esp-dimmer/**

Затем:

1. Подключите ESP32-C3 к компьютеру USB-кабелем с передачей данных.
2. Нажмите **«Установить прошивку»**.
3. Выберите появившееся устройство ESP32-C3.
4. Подтвердите установку и дождитесь завершения записи.

Установщик использует ESP Web Tools и готовый объединённый образ прошивки. Локальная среда разработки не требуется.

> Web Serial требует HTTPS и совместимый настольный браузер. ESP Web Tools указывает поддержку Google Chrome, Microsoft Edge и браузеров с доступным Web Serial. На Android/iOS рассчитывать на этот сценарий не следует — для прошивки используйте компьютер.

### Если плата не появляется

1. Проверьте, что USB-кабель поддерживает передачу данных.
2. Зажмите **BOOT**.
3. Нажмите и отпустите **RESET**.
4. Отпустите **BOOT**.
5. Повторите подключение в Web Installer.

Пока power-path конкретной ESP32-C3 SuperMini не проверен, не подключайте одновременно USB и внешний источник питания.

## Вариант 2 — скачать образ из GitHub Release

Каждый ESP32-C3 release содержит:

- `esp-dimmer-vX.Y.Z-full.bin` — полный образ для установки на чистую плату;
- `esp-dimmer-vX.Y.Z-firmware.bin` — только приложение, в основном для разработки/обновления при известной разметке flash;
- `SHA256SUMS.txt` — контрольные суммы релизных бинарников.

Для стороннего пользователя нужен именно **`full.bin`**.

Полный образ уже включает:

- bootloader;
- partition table;
- `boot_app0.bin`;
- основную прошивку ESP Dimmer.

Он формируется через `esptool merge_bin` и предназначен для записи с offset `0x0`.

Релизы: https://github.com/Web-Usov/esp-dimmer/releases

### Как установить скачанный `full.bin` на ESP32-C3

Само скачивание `.bin` **не прошивает плату**: файл нужно записать во flash-память ESP32-C3. Для этого можно использовать браузерный прошивальщик **Espressif ESP Tool** — без PlatformIO, Arduino IDE и Python.

1. Откройте нужную версию в [GitHub Releases](https://github.com/Web-Usov/esp-dimmer/releases) и в разделе **Assets** скачайте файл вида `esp-dimmer-vX.Y.Z-full.bin`. Например, для первого релиза — [`esp-dimmer-v0.1.0-full.bin`](https://github.com/Web-Usov/esp-dimmer/releases/download/v0.1.0/esp-dimmer-v0.1.0-full.bin). **Не выбирайте** `firmware.bin` для этого сценария.
2. Подключите **ESP32-C3 SuperMini** к компьютеру **USB-кабелем с передачей данных**. Пока схема питания платы не проверена, не подключайте одновременно USB и внешнее питание.
3. В **Google Chrome** или **Microsoft Edge** на компьютере откройте официальный прошивальщик Espressif: **https://espressif.github.io/esptool-js/**. Он использует Web Serial.
4. В разделе **Program** нажмите **Connect**, выберите последовательный порт подключённой ESP32-C3 (`COMx` в Windows или порт вида `/dev/cu.usbmodem...` в macOS) и разрешите браузеру доступ. Если есть выбор скорости (**Baudrate**), для первого раза удобно использовать **115200**.
5. Нажмите **Add File** и выберите скачанный `esp-dimmer-vX.Y.Z-full.bin`. Для этого файла установите **Flash Address = `0x0`**. Это **обязательный адрес**: в одном `full.bin` уже находятся загрузчик, разделы и приложение. Если прошивальщик предлагает параметры flash, используйте соответствующие релизному образу **DIO**, **80 MHz**, **4 MB**.
6. Нажмите **Program** и дождитесь сообщения об успешной записи. Во время прошивки **не отключайте USB**.
7. После завершения отключитесь от прошивальщика и нажмите **RESET** на плате (или переподключите USB). ESP Dimmer запустится; **все четыре PWM-канала после загрузки должны быть выключены**.

**Важно:** файл `firmware.bin` содержит только приложение и **не является** заменой `full.bin` при записи с адреса `0x0`. Для установки на чистую плату или перехода с другой прошивки используйте именно `full.bin`.

### Если прошивальщик не видит плату или запись не начинается

1. Проверьте USB-кабель (зарядные кабели без линий данных не подходят), порт компьютера и закройте программы, занявшие COM/serial-порт, например Serial Monitor.
2. Переведите ESP32-C3 в режим загрузчика: **зажмите BOOT → нажмите и отпустите RESET → отпустите BOOT**. Затем снова нажмите **Connect** и выберите появившийся порт.
3. Если связь обрывается, попробуйте меньшую скорость (**115200**) и подключение напрямую к USB-порту без хаба.
4. При ошибке запуска после успешной записи убедитесь, что выбран именно образ для **ESP32-C3**, указан адрес **`0x0`**, а плата перезагружена. Не используйте без необходимости **Erase Flash**: полное стирание удаляет данные, которые могли храниться на устройстве.

### Альтернатива для опытных пользователей — esptool в терминале

Если браузерная прошивка недоступна, можно использовать официальный **esptool**. Этот способ уже **требует установленного Python**:

```bash
python -m pip install esptool
python -m esptool --chip esp32c3 --port COM5 write-flash 0x0 esp-dimmer-v0.1.0-full.bin
```

Выполняйте команду из папки со скачанным `.bin`. Замените `COM5` на порт своей платы (например, `/dev/cu.usbmodem...` на macOS или `/dev/ttyACM0` на Linux), а имя файла — на нужную версию. Если esptool не подключается, используйте последовательность **BOOT + RESET** выше. После успешной записи перезапустите плату.

Подробности по инструментам: [Espressif esptool-js](https://github.com/espressif/esptool-js) и [документация esptool](https://docs.espressif.com/projects/esptool/en/latest/esp32c3/esptool/index.html).

## Как обновляется Web Installer

Публикация автоматизирована в `.github/workflows/release.yml`:

1. GitHub Actions собирает `esp32c3` через PlatformIO.
2. Создаёт versioned `firmware.bin` и объединённый `full.bin`.
3. Публикует оба бинарника и `SHA256SUMS.txt` в GitHub Release.
4. Для **стабильного** релиза создаёт статический сайт установщика, кладёт туда `full.bin` и manifest ESP Web Tools.
5. GitHub Pages публикует этот сайт по адресу `https://web-usov.github.io/esp-dimmer/`.

Prerelease (`vX.Y.Z-rc.N`, `vX.Y.Z-alpha.N` или релиз, вручную отмеченный как prerelease) **не обновляет** публичный Web Installer. Это защищает обычных пользователей от случайной установки тестовой версии.

## Однократная настройка GitHub Pages

Для первого запуска Pages в репозитории необходимо один раз выбрать:

**Settings → Pages → Build and deployment → Source → GitHub Actions**.

После этого следующие стабильные релизы обновляют Web Installer автоматически.

## Для разработчика

Сборка и загрузка из исходников по-прежнему доступны через PlatformIO. Основные команды и настройки описаны в корневом `README.md`.
