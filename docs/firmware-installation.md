# Установка готовой прошивки ESP Dimmer

Для обычной установки ESP Dimmer на **ESP32-C3** не нужны исходники, PlatformIO, Python или Arduino IDE.

## Вариант 1 — Web Installer (рекомендуется)

Откройте:

**https://web-usov.github.io/esp-dimmer/**

Затем:

1. Подключите ESP32-C3 к компьютеру USB-кабелем с передачей данных.
2. Нажмите **«Установить прошивку»**.
3. Выберите появившееся устройство ESP32-C3.
4. Подтвердите установку и дождитесь завершения записи.

Установщик использует ESP Web Tools и готовый объединённый образ прошивки. Локальная среда разработки не требуется.

> Web Serial требует HTTPS и совместимый настольный браузер. ESP Web Tools указывает поддержку Google Chrome, Microsoft Edge и браузеров с доступным Web Serial. На Android/iOS рассчитывать на этот сценарий не следует — для прошивки используйте компьютер.

### Если плата не появляется

1. Проверьте, что USB-кабель поддерживает передачу данных.
2. Зажмите **BOOT**.
3. Нажмите и отпустите **RESET**.
4. Отпустите **BOOT**.
5. Повторите подключение в Web Installer.

Пока power-path конкретной ESP32-C3 SuperMini не проверен, не подключайте одновременно USB и внешний источник питания.

## Вариант 2 — скачать образ из GitHub Release

Каждый ESP32-C3 release содержит:

- `esp-dimmer-vX.Y.Z-full.bin` — полный образ для установки на чистую плату;
- `esp-dimmer-vX.Y.Z-firmware.bin` — только приложение, в основном для разработки/обновления при известной разметке flash;
- `SHA256SUMS.txt` — контрольные суммы релизных бинарников.

Для стороннего пользователя нужен именно **`full.bin`**.

Полный образ уже включает:

- bootloader;
- partition table;
- `boot_app0.bin`;
- основную прошивку ESP Dimmer.

Он формируется через `esptool merge_bin` и предназначен для записи с offset `0x0`.

Релизы: https://github.com/Web-Usov/esp-dimmer/releases

## Как обновляется Web Installer

Публикация автоматизирована в `.github/workflows/release.yml`:

1. GitHub Actions собирает `esp32c3` через PlatformIO.
2. Создаёт versioned `firmware.bin` и объединённый `full.bin`.
3. Публикует оба бинарника и `SHA256SUMS.txt` в GitHub Release.
4. Для **стабильного** релиза создаёт статический сайт установщика, кладёт туда `full.bin` и manifest ESP Web Tools.
5. GitHub Pages публикует этот сайт по адресу `https://web-usov.github.io/esp-dimmer/`.

Prerelease (`vX.Y.Z-rc.N`, `vX.Y.Z-alpha.N` или релиз, вручную отмеченный как prerelease) **не обновляет** публичный Web Installer. Это защищает обычных пользователей от случайной установки тестовой версии.

## Однократная настройка GitHub Pages

Для первого запуска Pages в репозитории необходимо один раз выбрать:

**Settings → Pages → Build and deployment → Source → GitHub Actions**.

После этого следующие стабильные релизы обновляют Web Installer автоматически.

## Для разработчика

Сборка и загрузка из исходников по-прежнему доступны через PlatformIO. Основные команды и настройки описаны в корневом `README.md`.
