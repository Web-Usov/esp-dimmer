ESP Dimmer

Установка готовой прошивки на ESP32-C3 прямо из браузера — без PlatformIO, Python и сборки проекта.

  1. Подключите ESP32-C3 к компьютеру USB-кабелем с передачей данных.
  2. Нажмите Установить прошивку и выберите появившееся устройство ESP32-C3.
  3. Подтвердите установку и дождитесь завершения записи.
Для установки нужен браузер с Web Serial на настольном компьютере — например Chrome, Edge или Firefox с поддержкой Web Serial. Откройте эту страницу по HTTPS: Web Serial недоступен на небезопасных страницах.

Установщик автоматически работает только с образом для ESP32-C3.

Если плата не определяется: зажмите BOOT, нажмите и отпустите RESET, затем отпустите BOOT и повторите подключение. Пока силовая часть конкретной платы не проверена, не подключайте одновременно USB и внешний источник питания.

Что устанавливается

Web Installer записывает объединённый образ esp-dimmer-full.bin с bootloader, таблицей разделов и основной прошивкой, начиная с адреса 0x0.
